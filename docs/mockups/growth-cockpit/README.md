# Макеты: growth-cockpit

Интерактивный макет того, как Socstat помогает вести контент для своих проектов: конкуренты → идеи → календарь → публикация → аналитика → реклама. План работ — в [docs/growth-cockpit-plan.md](../../growth-cockpit-plan.md).

Это не рабочий код: страница не ходит в API, данные вымышленные, публикация не выполняется. Продакшен-код не менялся.

## Как открыть

Откройте [index.html](index.html) в браузере — файл самодостаточный, сервер не нужен. Или с сервера:

```bash
open docs/mockups/growth-cockpit/index.html
```

Что щёлкать:

- **Меню слева** — восемь экранов.
- **Переключатель проекта** (карточка под логотипом) — Money Planner и Socstat; у первого два канала (ВК и Telegram), у второго один (ВК).
- **Календарь** — стрелки месяца, «Сегодня», «Месяц / Неделя», фильтры каналов, чипы публикаций и «+ещё». Чип открывает карточку справа.
- **Конкуренты** — «Взять идею» добавляет идею и увеличивает счётчик в меню.
- **Идеи** — «В черновик» открывает черновик с заготовкой.
- **Черновик** — «Сгенерировать» показывает заглушку генерации, «Запланировать» добавляет пост в календарь.
- **Аналитика** — фильтры каналов, график, «что работает», список постов.

## Что учтено

- Два проекта — два набора каналов и правил; переключатель меняет данные, а не только заголовок.
- Календарь показывает статусы: идея, черновик, запланировано, вышло.
- В аналитике у ВК подписки точные, у Telegram — с пометкой «оценка».
- Дизайн-код — палитра, шрифт и шаблон обложки; текст на обложке рисуется, а не генерируется.
- ChatGPT выбран провайдером, DeepSeek указан фолбэком через прокси.
- «Открыть проект другим» выключено — сначала собственный опыт.

## Что нужно решить перед кодом

1. Порядок фаз: календарь и конкуренты раньше публикации или наоборот?
2. Где живёт проект Money Planner: отдельный аккаунт или второй проект в том же?
3. Один общий бот Telegram или свой на проект?
4. Показывать конкурентов в абсолютных цифрах или только «× к медиане»?
5. Нужен ли на обзоре блок «что работает» или достаточно календаря и аналитики?
