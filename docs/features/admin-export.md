# Выгрузка аналитики для агента

Кнопка «Выгрузить» в админке на вкладке «Посещаемость» скачивает JSON-сводку о состоянии Socstat за выбранный там период (7, 30 или 90 дней). Файл нужен, чтобы отдать его агенту и обсуждать с ним дела, делать выводы и строить планы: в нём есть пояснения к каждому разделу, так что агенту не нужен доступ к коду.

## Что внутри

- `about` — дата выгрузки, период, часовой пояс и пояснения к метрикам (`notes`).
- `pricing` — текущие цены для новых и старые цены для тех, кто уже платил.
- `totals` — всего пользователей, с активным доступом, плательщиков, платежей и выручки за всю историю.
- `monthly` — последние 12 месяцев: регистрации по источникам первого касания, платежи, выручка, плательщики и впервые заплатившие.
- `activity` — то же, что показывает вкладка «Посещаемость»: сводки по периодам, по дням, вовлечённость, воронка, источники, возвраты по рекламе, каналы, страницы, действия, устройства, часы, лента.
- `preview` — краткий отчёт без доступа, `push` — уведомления в браузере (как в соответствующих блоках админки).
- `recentPayments` — платежи за период: сумма, тариф, первый ли это платёж, дата регистрации, дней от регистрации до оплаты, источник и кампания.

Администраторы исключены, деньги — только успешные платежи больше нуля, дни и месяцы считаются по Москве. Имён, VK ID и внутренних ID в файле нет: пользователь в ленте и платежах обозначен ключом `u1`, `u2`…, который совпадает только внутри одной выгрузки.

## Доступ по токену

Агент может забирать выгрузку сам, без входа через VK: запрос с заголовком `Authorization: Bearer <токен>` проходит, если токен совпадает с `ADMIN_EXPORT_TOKEN` в `api/.env` на сервере. Пустой `ADMIN_EXPORT_TOKEN` выключает этот вход — остаётся только кнопка в админке. С неверным токеном или без авторизации ответ 401; запрос с сессией не-администратора — 403. Токен даёт доступ только к этой выгрузке, остальная админка по нему не открывается.

Локально токен хранится в `.env.local` в корне репозитория как `SOCSTAT_EXPORT_TOKEN`; как им пользоваться агенту — в `.agents/rules/socstat-status.md`. Сменить токен: сгенерировать новый (`openssl rand -hex 32`), заменить в обоих местах и перезапустить API.

## Код

- `api/src/services/adminExportService.ts` — сборка сводки; переиспользует `getAdminActivityStats`, `getAdminPreviewStats`, `getAdminPushStats`.
- `GET /api/account/admin/export?days=30` в `api/src/routes/account.ts` — администратор по сессии или запрос с токеном.
- Кнопка — `src/components/AdminActivityStats.tsx`.

## Ограничения

Визиты, отказы и действия есть только с начала трекинга (`activity.trackingSince`); регистрации, каналы и оплаты — за всю историю. В `totals.users` входят пользователи, перенесённые со старого сайта. Выгрузка считается на лету и ничего не сохраняет.
