# Макет: раздел «Контент-план»

Новый раздел Socstat — сразу под «Аналитикой». Внутри две вкладки: **Календарь** и **Идеи**. Раздел «Идеи для постов» переехал в «Идеи»; «Контент» (проекты, рубрики, правила) пока остаётся отдельным админским разделом. Вкладку «Проекты» внутри «Контент-плана» не делаем.

Макет статичный: данные вымышленные, запросов к API нет, реальная публикация не выполняется — кнопка «Опубликовать сейчас» и автопубликация показывают сценарий.

## Как открыть

- В браузере: [http://127.0.0.1:8788/](http://127.0.0.1:8788/) (пока запущен локальный сервер).
- Или файлом: [index.html](index.html) — открывается двойным кликом.

## Вкладки

### Календарь

- Фильтры по каналам слева, месяц и «Сегодня» справа.
- Календарь и **правая колонка**: каналы для публикации, автопубликация и черновики. Блок «Идеи ИИ» с календаря убран — идеи во вкладке.
- Месяц, статусы: черновик, запланирован, опубликован.
- Клик по дню — правая панель: публикации этого дня и форма нового поста.
- Клик по посту — редактирование.
- Недельного вида нет.

### Идеи

- Все идеи ИИ: источник, метрика, причина, заготовка.
- Фильтр по источнику: все, конкуренты, мои посты, сезонные.
- Ограничений нет: обновление вручную, кнопка «Обновить».
- Ниже — «Лучшие посты в нише» (бывший раздел «Идеи для постов»): источник, просмотры, «В план».

## Каналы для публикации

- В правой колонке — список подключённых групп и каналов: ВКонтакте и Telegram отдельными блоками.
- У каждого: название, подписчики и зелёный статус «подключён».
- Внизу — «Подключить группу или канал» (в демо заглушка).
- Именно эти каналы доступны в форме поста. Если канал отключить, он исчезнет из выбора и из автопубликации.

## Автопубликация

- Запланированный пост выходит сам в указанные дату и время.
- В правой колонке — карточка «Автопубликация»: переключатель, сколько постов выйдет автоматически, ближайший пост и кнопка настроек.
- Когда автопубликация выключена, карточка пишет, что посты будут ждать подтверждения.
- В форме поста: строка «Автопубликация включена / выключена», статус «канал подключён» и кнопка **«Опубликовать сейчас»**.
- «Опубликовать сейчас» переносит пост на сегодня, ставит статус «опубликован» и показывает тост. В демо отправка не выполняется.

## Доступ

Раздел включён **только для администраторов**. В шапке раздела есть плашка «Только для админов»: по клику открывается настройка:

- выключено;
- только администраторам (как сейчас);
- всем пользователям.

В продукте это будет переключатель в «Админке → Настройки». В макете видимость страницы не меняется — плашка и модалка только показывают настройку. После «всем» щит в навигации исчезает и плашка становится зелёной.

Важно: «Идеи для постов» были доступны всем, а «Контент-план» пока только администраторам. После переноса идеи тоже станут админскими, пока раздел не включат для всех.

## Форма поста

- **Один пост — один канал.** Кросс-постинг не делаем: разметка ВК и Telegram отличается. В форме это написано под выбором канала.
- Канал: ВК или Telegram, сгруппировано; рядом — «канал подключён».
- Дата и время; у черновика дата может быть пустой.
- Markdown под площадку:
  - ВК: `**жирный**`, `*курсив*`, `__подчёркнутый__`, `[ссылка|текст]`, списки с «—»; заголовки, таблицы и код не поддерживаются.
  - Telegram: `**жирный**`, `__курсив__`, `` `код` ``, `[текст](ссылка)`, цитаты `>`.
- Счётчик и лимит: 16 000 для ВК, 4 096 для Telegram.
- «Предпросмотр» — как пост будет выглядеть в выбранной соцсети.
- «Сохранить черновик», «Опубликовать сейчас» и «Запланировать»; у запланированного — «Сохранить».
- Опубликованные посты только для чтения.

## Идеи ИИ

- Источники: посты конкурентов, ваши лучшие посты, сезонные поводы, комментарии аудитории.
- У каждой идеи виден источник и метрика, а не «ИИ так решил».
- «В план» открывает форму с текстом, датой «сегодня» и каналом по фильтру.
- «Скрыть» убирает идею.
- Ограничений нет; обновление вручную.
- Факты и цифры проверяет человек — это написано в блоке и в панели.

## Решения

1. **Фильтры слева, месяц справа.**
2. **Правая колонка на странице:** каналы для публикации, автопубликация и черновики. Календарь стал компактнее.
3. **Блок «Идеи ИИ» с календаря убран** — идеи живут во вкладке.
4. **Один пост — один канал.**
5. **Автопубликация включена** по умолчанию; её можно выключить, тогда посты ждут подтверждения.
6. **Без недельного вида.**
7. **Без напоминаний.**
8. **Раздел только для администраторов**; включение для всех — через «Админку».
9. **Идеи без лимитов.**
10. **«Идеи для постов» внутри «Контент-плана»; «Контент» остаётся отдельным.** От вкладки «Проекты» пока отказались.

## Что нужно решить

1. Автопубликация: глобального переключателя достаточно или нужен режим подтверждения для отдельных постов?
2. Каналы: нужен ли в списке статус доступа (бот-админ, истёкший токен) и редактирование прямо в колонке?
3. Подтвердить: «Идеи для постов» переехали в «Идеи», «Контент» остаётся отдельным, вкладку «Проекты» не делаем.
4. Фильтр идей по источникам (конкуренты / мои / сезонные) — оставить?
5. Доступ по умолчанию «только администраторам»; включать всем через «Админку» — ок?
6. Если позже вернёмся к проектам: что в них должно быть, кроме рубрик, конкурентов и правил?

## Прямые ссылки

- `?tab=ideas` — вкладка идей.
- `?access=1` — настройка доступа.
- `?post=p10` — редактирование поста.
- `?post=p10&preview=1` — сразу предпросмотр.
- `?day=2026-11-27` — новый пост на день.
