# Отчёт во VK

По понедельникам Socstat присылает итоги недели сообщением от сообщества socstat во VK: прирост подписчиков по источникам с дашборда, лучший пост недели и место среди конкурентов. Отчёт должен давать повод вернуться на сайт, а пользователю без доступа — напоминать о продлении.

## Переключатель в админке

Фича управляется на вкладке «Настройки» админки, блок «Фичи» (`FeatureFlag` с ключом `vkReports`):

| Режим | Что происходит |
| --- | --- |
| Выключено (по умолчанию, документа нет) | Плашки и блока в профиле нет, отчёты не уходят. Callback API продолжает записывать, кто разрешил или запретил сообщения, но ничего не отвечает. |
| Только администраторам | Плашку, блок в профиле, приветствие и отчёт видят только администраторы. Режим для проверки на проде. |
| Всем пользователям | Фича включена всем. |

Режим кешируется в каждой реплике API на 30 секунд. Там же кнопка «Отправить отчёт себе»: собирает отчёт администратора за последние 7 дней (в любой день недели), показывает текст и отправляет его во VK, если у администратора подключены сообщения.

Фича считается включённой пользователю, только если на сервере задан `VK_GROUP_TOKEN`.

## Как пользователь подключается

Сообщество может писать только тем, кто разрешил ему сообщения или написал первым. VK ID пользователя известен по входу, поэтому отдельной привязки нет.

1. «Подключить» есть в четырёх местах, все — только пока сообщения не подключены:
   - **плашка** «Присылать итоги недели во VK?» под шапкой — когда на дашборде есть хотя бы один источник. Доступ не нужен. После «Не сейчас» скрывается на 3 недели (`localStorage`);
   - **ссылка «Итоги недели во VK»** под заголовком «Отслеживаемые источники» на главной — постоянно; после подключения на её месте отметка «Итоги недели приходят во VK» (если отчёт не выключен);
   - **строка в панели конкурентов** «Присылать место среди конкурентов раз в неделю во VK?» — когда в наборе есть хотя бы один конкурент. Панель встроена в аналитику, поэтому сама загружает `/api/notifications/settings`;
   - **блок «Отчёт во VK» в профиле**.

   Одна просьба за визит: пока плашка отчёта видна, плашка push-уведомлений не показывается, а если плашку отчёта показали в этом визите (закрыли, подключили или просто увидели), запрос push ждёт следующего визита (`sessionStorage`).
2. «Подключить» открывает диалог с сообществом (`https://vk.com/write-<SOCSTAT_VK_GROUP_ID>`). Человек пишет любое сообщение или разрешает сообщения в сообществе.
3. Callback API присылает событие `message_new` или `message_allow`, у пользователя ставится `notifications.vk.allowed`, и сообщество отвечает приветствием (один раз, при подключении). Сайт обновляет аккаунт по SSE, плашка исчезает.
4. Если событие не дошло (например, человек разрешил сообщения раньше, чем настроили Callback API), кнопка «Проверить» спрашивает VK напрямую — `messages.isMessagesFromGroupAllowed`.

В профиле блок «Отчёт во VK»: подключить, проверить, включить и выключить отчёт (`notifications.weeklyReport`). В диалоге с сообществом работают команды «стоп» и «старт». Событие `message_deny` или ошибка VK 900–902 при отправке снимают `allowed`.

## Что в отчёте

Неделя — от ночного среза в прошлый понедельник до среза в день отчёта (см. [snapshots.md](snapshots.md)). Если среза за день нет, берётся соседний день; без него прирост неизвестен. Живых запросов к VK, YouTube и Telegram нет — всё из `ChannelSnapshot` и `PostSnapshot`.

До 5 первых отслеживаемых источников дашборда (`SavedGroup`, порядок дашборда), по каждому:

- подписчики и прирост за неделю (число и процент);
- полный отчёт (активный доступ, у администратора — без включённых ограничений тарифа) — ещё прирост неделей раньше, самый просматриваемый пост, опубликованный за неделю, со ссылкой и место по проценту роста среди конкурентов из набора (`CompetitorSet`) с лидером, если он обогнал;
- урезанный отчёт (доступ закончился не больше 8 недель назад) — только подписчики и прирост, внизу цена месяца: сохранённая старая для тех, кто платил, иначе текущая. Позже отчёт перестаёт приходить.

Отчёт не отправляется, если ни у одного источника нет свежего среза. Ссылки ведут на `/app/dashboard` или `/app/account` с метками `utm_source=vk_msg&utm_medium=messenger&utm_campaign=weekly`, поэтому переход учитывается как возврат по рекламе (`ad_return` с меткой `vk_msg / weekly`).

## Расписание и отправка

Планировщик (`startWeeklyReportScheduler`) каждые 15 минут с 10:00 до 21:00 по Москве проверяет, понедельник ли, и отправляет отчёт всем подключившим сообщения с включённым отчётом (в режиме «Только администраторам» — только им). Каждая отправка записывается в `NotificationDelivery`; уникальный индекс по пользователю, виду и дате понедельника не даёт отправить отчёт дважды из двух реплик. Между сообщениями — пауза 150 мс. Ошибка отправки записывается в `error` и повторно в эту неделю не отправляется.

## Статистика

Блок «Отчёт во VK» во вкладке «Посещаемость» и раздел `vkReports` в [выгрузке](admin-export.md): режим фичи, сколько подключили сообщения и включили отчёт, где нажимали «Подключить» (событие `vk_report_connect` с местом: `banner`, `dashboard`, `competitors`, `profile`) и сколько из нажавших сейчас подключены, сколько отчётов ушло (полных и урезанных), сколько перешли по ссылке и оплатили в течение 7 дней после отчёта, сколько не доставлено. Администраторы исключены.

## Настройка сообщества

В управлении сообществом socstat:

1. «Сообщения» — включить сообщения сообщества.
2. «Работа с API» → «Ключи доступа» — создать ключ с правом «Сообщения сообщества», записать в `VK_GROUP_TOKEN`.
3. «Работа с API» → «Callback API» — адрес `https://socstat.ru/api/notifications/vk/callback`, строку подтверждения записать в `VK_CALLBACK_CONFIRMATION`, придумать секретный ключ и записать его в `VK_CALLBACK_SECRET`. Версия API — 5.131. Типы событий: «Входящее сообщение», «Разрешение на получение», «Запрет на получение».
4. Пересоздать контейнер API (`docker compose -f docker-compose.prod.yml up -d api`) и нажать «Подтвердить» в настройках Callback API.

Переменные в `api/.env`: `VK_GROUP_TOKEN`, `VK_CALLBACK_CONFIRMATION`, `VK_CALLBACK_SECRET`, `SOCSTAT_VK_GROUP_ID` (по умолчанию 125792332), `WEEKLY_REPORTS_ENABLED` (планировщик, по умолчанию включён только в production).

## Код

- `api/src/services/featureFlags.ts`, модель `FeatureFlag` — режимы фич; маршруты `GET/POST /api/account/admin/features`.
- `api/src/services/vkCommunityMessages.ts` — `messages.send` и проверка разрешения ключом сообщества.
- `api/src/services/vkReports.ts` — сборка отчёта, рассылка, подключение и команды; `vkReportUtils.ts` — расчёты и текст (тесты рядом).
- `api/src/routes/notifications.ts` — `/api/notifications/settings`, `vk/check`, `vk/callback`, `admin/test-weekly`, `admin/stats`; `vkReportStatsService.ts` — статистика.
- Поле `notifications` в модели `User`, модель `NotificationDelivery`.
- `src/components/VkReports.tsx` — плашка, ссылка на главной, строка в панели конкурентов и блок в профиле; `src/components/AdminFeatureFlags.tsx` — переключатель в админке. Состояние приходит в `/api/account/me` полем `vkReports`.
