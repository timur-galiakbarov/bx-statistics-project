# Как работает Socstat

Описания работающего функционала: что делает фича, откуда берёт данные, где лежит код, какие есть ограничения и настройки. Планы и журналы переезда лежат уровнем выше, в `docs/`.

- [Деплой](deploy.md) — пуш в `master` автоматически выкатывается на прод.
- [Ночные срезы](snapshots.md) — ежедневное сохранение подписчиков и счётчиков публикаций VK, YouTube и Telegram.
- [Конкуренты](competitors.md) — наборы конкурентов и сравнение с ними.
- [Оплата](payments.md) — тарифы, ЮMoney, подтверждение платежей и время оплаты.
- [Пользователи в админке](admin-users.md) — списки последних активных пользователей и пользователей с доступом.
- [Выгрузка аналитики](admin-export.md) — JSON-сводка из админки для разговора с агентом о состоянии сервиса.

## Правило

Каждая фича описывается здесь — подробности в [.agents/rules/feature-docs.md](../../.agents/rules/feature-docs.md).
