# Показатели сервера в админке

Вкладка «Сервер» показывает загрузку CPU, использованную и доступную RAM, доступное место на диске и время измерения. Данные загружаются при открытии вкладки и по кнопке «Обновить»; история не сохраняется.

Маршрут `GET /api/account/admin/server-metrics` доступен только вошедшему администратору. Он вызывает `api/src/services/serverMetrics.ts`; интерфейс находится в `src/components/AdminServerMetrics.tsx`. CPU измеряется по изменению счётчиков за полсекунды. В Linux доступная RAM берётся из `MemAvailable` в `/proc/meminfo`, иначе используется свободная память. Использованная RAM — общая минус доступная. Место на диске учитывает пространство, доступное пользователю API.

По умолчанию показывается файловая система пути `/`. Переменная `SERVER_METRICS_DISK_PATH` задаёт другой существующий путь, например путь к данным базы. При недоступном пути вкладка покажет ошибку. После изменения переменной перезапустите API.

При запуске API напрямую через PM2 показатели относятся к его серверу. В контейнере показатели зависят от доступных ему системных данных, а диск `/` может относиться к файловой системе контейнера, а не к разделу с данными. Для показателей нужного раздела его путь должен быть доступен API; схема запуска на проде требует отдельной проверки.
