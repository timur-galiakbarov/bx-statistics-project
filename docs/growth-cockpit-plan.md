# План: Socstat как growth-cockpit

Статус: черновик плана. Код не писан. Кликабельные макеты — в [docs/mockups/growth-cockpit](mockups/growth-cockpit/README.md).

## Зачем

Socstat умеет измерять. Владельцу продукта с каналами нужно не измерять, а расти: понимать, о чём писать, когда выходит пост, что он принёс и куда вложить рекламу.

Продукт — один цикл: **конкуренты → идеи → план → публикация → аналитика → реклама → снова конкуренты**. Первый пользователь — я сам (Money Planner и Socstat). Второй — такие же одиночки с 1–3 своими каналами.

Принцип: каждая фаза полезна сама по себе. Не big bang, а шесть работающих шагов.

## Как это выглядит в жизни

- **Понедельник.** Открываю «Конкурентов»: 12 постов за неделю, у трёх охват в 2–4 раза выше медианы. Беру идеи.
- **Вторник.** В «Идеях» выбираю три, ставлю в календарь на среду–пятницу.
- **Среда.** Открываю черновик, генерирую ChatGPT, правлю под правила проекта, выбираю обложку из дизайн-кода.
- **Четверг.** Подтверждаю публикацию — в ВК и TG, в разное время.
- **Пятница.** Посты вышли. Вижу id и ссылки в календаре.
- **Понедельник.** В аналитике: какие темы дали подписки, какие — только просмотры. Лучшие темы уходят в правила. Площадки — если хочу ускорить.

## Экраны

| Экран | Что делает |
|---|---|
| Обзор | Здоровье проекта, цикл, «что делать сегодня», «что работает», ближайшие публикации. |
| Контент-план | Календарь месяц/неделя, дорожки каналов, статусы: идея → черновик → запланировано → вышло. |
| Конкуренты | Набор на проект (ВК и TG), посты с охватом относительно медианы, «взять идею». |
| Идеи | Карточки: источник, угол, почему сработает, проверки. В черновик или отклонить. |
| Черновик | Редактор канала, правила проекта, дизайн-код, провайдер, предпросмотр ВК/TG. |
| Аналитика | Посты, просмотры, ER, подписки (ВК — точно, TG — оценка), темы и форматы. |
| Площадки | Существующий подбор + «продвинуть пост» из аналитики. |
| Настройки проекта | Каналы, конкуренты, brand kit, правила, провайдер, квоты. |

## Фазы

### 0. Фундамент: провайдер — 2–3 дня

- Абстракция провайдера: OpenAI (ChatGPT) и DeepSeek, выбор на проект.
- OpenAI через серверный прокси: VPN на ноутбуке прод не спасает. Переиспользовать паттерн SOCKS5 из Telegram-клиента.
- Лимиты и фолбэк: OpenAI упал — DeepSeek; квота на проект в сутки.
- Промпты под OpenAI переписать: другой формат ответов и послушность правилам.
- **Готово, когда:** черновик генерируется обоими провайдерами, при падении OpenAI запрос не ломается.

### 1. Конкуренты и идеи — 1–1,5 недели

- Конкуренты как источники с пометкой: ВК — `wall.get`, TG — существующий MTProto-клиент (чтение публичных каналов уже работает).
- Ранжирование постов по охвату относительно медианы канала (логика уже есть в «Контенте»).
- Генерация идей: «переосмысли, не копируй», с проверками и ссылками на исходные посты.
- Разметка постов: тема, формат, хук — чтобы аналитика отвечала не «сколько просмотров», а «какие темы дают подписки».
- **Готово, когда:** по проекту есть набор конкурентов, за неделю появляется 5–10 идей с источником и причиной.

### 2. Календарь и план — 5–7 дней

- `PlanItem`: проект, канал, дата и время, статус, идея, текст, медиа.
- Экран месяц/неделя, дорожки каналов, статусы, перенос.
- Связь с существующим «Контентом»: проект, рубрики, черновики.
- **Готово, когда:** можно спланировать неделю по трём каналам и увидеть это одним взглядом.

### 3. Дизайн-код и обложки — 1–1,5 недели

- Brand kit: палитра, шрифты, лого, сетки, набор шаблонов.
- Шаблон — слоты (заголовок, подпись, CTA); ИИ заполняет слоты, серверный рендер собирает PNG.
- Текст рисуется, а не генерируется: кириллица на AI-картинках всё ещё ломается.
- **Готово, когда:** у каждого поста обложка в одном стиле, без ручной вёрстки.

### 4. Публикация ВК + TG — 2–3 недели

- ВК: scope `wall` (сейчас `stats,groups,photos,video,offline`), переавторизация только у тех, кто публикует. Статистика продолжает работать на текущем токене.
- TG: бот-админ канала; MTProto-сессия для чтения не подходит.
- Расписание, подтверждение, идемпотентность (один пост не должен выйти дважды), ретраи, статус «не вышло».
- Привязка `externalPostId` к элементу календаря.
- **Готово, когда:** пост выходит по расписанию, сбой виден в календаре, повтор не дублирует публикацию.

### 5. Аналитика постов и подписок — 1,5–2 недели

- ВК: `partnerStats.getContentStatsAllTime` уже отдаёт по каждому посту `subscriptions`, `group_visits`, `link_clicks`; `getContentStatsByPeriod` — просмотры, лайки, репосты, скрытия. Это прямая цифра, не корреляция.
- TG: подписки по посту недоступны. Оценка: дельта подписчиков в окне ±24 ч против базовой линии, либо трекинг-ссылка. Помечать «оценка».
- Отчёт «что работает»: тема и формат → подписки на пост.
- Обратная связь в правила: лучшие темы подставляются в генерацию.
- **Готово, когда:** на вопрос «что публиковать» есть ответ с цифрами, а не интуиция.

### 6. Реклама — 2–4 недели, зависит от Money Planner

- Из аналитики: «продвинуть пост» → подбор площадок (уже есть) → шортлист.
- Аналитика рекламы: расход, переходы, регистрации, оплаты.
- **Зависимость:** нужен сайт Money Planner с регистрациями и оплатами и метки (`utm`, `rb_clickid`, `yclid`). У Socstat это уже работает в админской выгрузке; для MP — отдельная интеграция.
- Если сайта нет — только расход и переходы; это нормально для старта, но называть это «аналитикой рекламы» нельзя.

### 7. Открытие другим — 1–2 недели

- Квоты и тарифы: генерация и постинг — лимитами, картинки — отдельно.
- Бета на 5–10 одиночках с 1–3 каналами.
- Только после того, как сам пользуюсь циклом каждый день.

## Модель данных

- `Channel`: проект, платформа (vk/tg), внешний id, название, статус доступа.
- `PlanItem`: проект, канал, дата/время, статус (idea/draft/scheduled/published/failed), идея, текст, медиа, `externalPostId`.
- `PostMetric`: PlanItem, дата, просмотры, охват, реакции, `subscriptions`, `groupVisits`, `linkClicks`, источник (vk/tg-estimate).
- `PostTag`: PlanItem, тема, формат, хук (ставит ИИ).
- `BrandKit`: проект, палитра, шрифты, лого, шаблоны.
- `Provider`: проект, провайдер, модель, лимиты.
- `AdCampaign` (позже): расход, источник, результат.

## Риски и решения

- **VK scope.** `wall` требует переавторизации; просить только у публикующих, статистику не ломать.
- **TG без per-post подписок.** Оценка или трекинг-ссылки; не выдавать за точность.
- **OpenAI из РФ.** Серверный прокси, лимиты, фолбэк на DeepSeek.
- **Дизайн-код.** Только шаблоны и слоты, не «нарисуй плакат».
- **Расползание.** Каждая фаза — рабочая; третья площадка не раньше, чем цикл приносит деньги.
- **Два проекта — два набора правил.** Общий brand kit можно, общие правила — нет.

## Метрики

- Время от идеи до запланированного поста — меньше 10 минут.
- 3+ поста в неделю на проект.
- Доля черновиков, опубликованных почти без правок.
- Подписки на пост (ВК — точно).
- Возврат в календарь на следующей неделе.
- Конверсия в оплату у беты.
