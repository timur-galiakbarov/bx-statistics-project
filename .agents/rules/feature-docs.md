# Описание функционала

В `docs/features/` лежат описания того, как работает Socstat: по файлу на фичу, список — в `docs/features/README.md`.

- Новая фича — в том же изменении добавить её описание в `docs/features/` и ссылку в `docs/features/README.md`.
- Изменилось поведение существующей фичи — обновить её описание.
- Работаешь с фичей, у которой описания нет, — написать его.

Описание отвечает на вопросы: что делает фича, откуда берёт данные, где лежит код, какие настройки и ограничения. README остаётся инструкцией по запуску и настройке, подробности работы — туда не писать, а ссылаться на `docs/features/`.
