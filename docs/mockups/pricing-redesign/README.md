# Макеты: страница тарифов и скидка

Статичные макеты для обсуждения. Это не рабочий код: страница не ходит в API, данные сообщества и цены — демонстрационные. Продакшен-код не менялся.

## HTML

- [pricing.html](pricing.html) — макет страницы тарифов. Варианты:
  - `pricing.html` — скидка выключена;
  - `pricing.html?discount=on` — скидка 20%;
  - `pricing.html?nosample=on` — без примера из отчёта.
- [admin-discount.html](admin-discount.html) — макет панели скидки в админке.
- [mock.css](mock.css) — общие стили макетов.

Карточки тарифов в HTML кликаются: выбранный срок меняет итог и кнопку.

## Что учтено

- Сначала польза: рост подписчиков, сравнение с конкурентами, лучшие публикации. Описано один раз, в карточках тарифов только срок и цена.
- Пример из отчёта — изменение подписчиков за 7 дней. Если данных нет, блок не показывается (вариант `nosample`).
- Месяц первый и выбран по умолчанию. В карточках — срок, полная сумма и цена в месяц для 3 и 12 месяцев.
- Скидка: обычная цена зачёркнута, итоговая крупно, сумма в кнопке совпадает с итогом.
- Телефон: одна колонка, крупная цена, кнопка на всю ширину.
- Админка: переключатель, процент 20, дата окончания, предпросмотр цен, выключено до ручного запуска. Отдельно проговорено, что старые цены и дневной тариф не участвуют.

## Что нужно решить перед кодом

- Оставляем ли пример именно по подписчикам или нужен ещё вариант с лучшим постом.
- Подходит ли жёлтый акцент для скидки или лучше держать всё в зелёном.
- Устраивает ли, что месяц выбран по умолчанию, а 3 месяца и год показываются без бейджа «выгодно».
- Нужен ли на телефоне отдельный экран с примером отчёта, или достаточно общего блока пользы.

## Вариант 2: компактные преимущества

После замечания «текст — вода, блок не нравится» добавлены два варианта с коротким блоком «В тариф входит»: только факты и цифры, без абзацев и без большой карточки-героя.

- `pricing-v2.html?discount=on` — над ценами, со скидкой;
- `pricing-v2.html?layout=below&discount=on` — под ценами, со скидкой;
- без `discount=on` — обычные цены.

### Что изменилось по наполнению

- Убран большой первый экран с тремя карточками и абзацами.
- Вместо него — три пункта: «Рост подписчиков · 7 / 30 / 90 дней», «Сравнение с конкурентами · до 10 сообществ: просмотры, ER, рост», «Лучшие публикации · топ по охвату и вовлечённости».
- Пример из отчёта — одна строка: сообщество, +124 за 7 дней, маленький график. Без поясняющего текста.
- Убраны повторяющиеся «Полная сумма · без автопродления» из каждой карточки. Осталась одна строка под тарифами.
- Скидка — одна строка: «−20% · Скидка на первую покупку · до 30 ноября».
