# Изменение кода — только после аппрува

НЕ начинать менять код без явного согласия пользователя.

- Сначала опиши, что собираешься сделать: какие файлы и что в них поменяется. Править можно только после явного «да».
- Вопрос, просьба разобраться или найти причину — это не разрешение на правку: ответь, предложи изменение и дождись согласия.
- Согласие действует на то изменение, о котором договорились. Если по ходу понадобилось менять что-то сверх оговорённого — снова спроси.
- Читать код, искать, запускать тесты и выгрузки без изменений можно без аппрува.
