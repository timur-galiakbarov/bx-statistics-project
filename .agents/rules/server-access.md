# Вход на сервер — только с согласия

Не заходить на прод-сервер без явного разрешения пользователя: ни по SSH, ни через `docker exec`, ни любым другим способом выполнить команду на хосте.

- Вопрос про сервер («что там с местом», «почему упало», «сколько памяти») — это не разрешение на заход. Сначала спроси и назови, что собираешься проверить: команды и зачем они нужны.
- Согласие действует на один оговорённый заход с оговоренными командами. Нужны новые команды или ещё один заход — спроси снова.
- Даже при разрешённом заходе ничего не удалять, не перезапускать и не менять на сервере без отдельного согласия: чистка кэша, перезапуск сервиса, правка конфигов — отдельный вопрос.
- Без аппрува можно работать с репозиторием: читать код, `docker-compose.prod.yml`, `deploy/`, `docs/features/deploy.md`.
- Адрес сервера, пользователя, пути к ключам и содержимое `api/.env` в ответах не выводить.

Если диагностика нужна, а разрешения нет — предложи пользователю готовый список команд, чтобы он выполнил их сам или разрешил заход агенту.
