T2Спринт 1

Подписки и отписки по дням + чистый прирост

VKДинамика подписчиков

Зачем

Сейчас виден только итог за период. При падении админ первым делом смотрит, в какой день ушли люди и сколько пришло взамен.

Данные

  • день без данных → пропуск, не ноль;
  • период > 90 дней → агрегация по неделям.

T3Спринт 1

Охват: всего / подписчики / виральный

VKСводная

Зачем

Главный вопрос админа: охват вырос за счёт своей аудитории или за счёт репостов? Сейчас видно только общее число.

Данные

partnerStats отдаёт reach.all, reach.subscribers, reach.viral. Сейчас забирается только all; subscribers считается в analyticsUtils, но не показывается, viral не запрашивается.

Состояния

  • нет прав → блок «Почему нет охвата»;
  • виральный недоступен → полоса из одного сегмента;
  • сумма долей всегда 100%, округление в подписи.

T4Спринт 1

Охват, сохранения, скрытия, клики и подписки у поста

VKПосты · карточка

Зачем

Сейчас пост измеряется только просмотрами и реакциями. Сохранения и клики показывают пользу, скрытия — раздражение. Это разница между «много посмотрели» и «пост сработал».

Данные

partnerStats.getContentStatsByPeriod: reach, bookmarks, hides, link_clicks, subscriptions. Сейчас используется только отладочный скрипт.

Состояния

  • старый пост → «—» вместо нуля;
  • скрытия = 0 → чип не подсвечивается;
  • сортировка по новым колонкам в тулбаре.

T5Спринт 1

Клипы и истории

VKСводная · новая вкладка «Контент»

Зачем

Клипы — главный драйвер охвата во VK, но в отчёте их нет вообще. Админ видит посты, а самый результативный формат — нет.

Данные

partnerStats.getContentStatsByPeriod с content_type: clip | story — метод и типы в коде уже есть, запросов нет.

Состояния

  • клипов нет → вкладка неактивна с объяснением;
  • истории без просмотров → скрываем ER, оставляем охват;
  • больше 30 единиц → «Показать ещё».

T6Спринт 1

Метрики поста на одинаковом возрасте (7 дней)

VKСводная · Аудитория · Посты

Зачем

Сейчас неделя сравнивается с неделей, но посты текущей недели моложе и всегда проигрывают. Выводы «стало хуже» могут быть ошибкой измерения.

Данные

Снимки постов PostSnapshot (24/48/72 ч и далее) + панель PostViewsCurvePanel. Для постов старше 7 дней берём значение «через 7 дней», для свежих — режим «сейчас» с пометкой.

Состояния

  • нет снимка на 7-й день → «—» и пояснение;
  • переключатель запоминается в адресе;
  • подпись под графиком меняется вместе с режимом.

T7Спринт 1

YouTube: подписчики и просмотры канала в KPI

YouTubeОбзор

Зачем

Сейчас «Просмотры» считают только видео, опубликованные в периоде. Канал, который живёт старыми видео, выглядит мёртвым, а роста подписчиков в KPI нет вовсе.

Данные

ChannelSnapshot (подписчики + добавить просмотры канала, задача 1 плана) и channelViewCount из публичных данных.

Состояния

  • меньше двух срезов → «нужно 2 дня истории»;
  • скрытые подписчики → «Недоступно»;
  • старые видео → отдельная строка «просмотры прошлых видео».

T8Спринт 2

Лучшее время публикации

VKTelegramПосты · новая панель

Зачем

Самый частый вопрос админа после «какой пост сработал» — «когда публиковать». Данные для ответа уже есть в постах за 90 дней.

Данные

wall.get / посты Telegram: дата, время, ER, просмотры. Время — МСК, как в остальном отчёте.

Состояния

  • ячейка с < 3 постами → приглушена, в подсказке «мало данных»;
  • меньше 20 постов всего → блок скрыт;
  • клик по ячейке → список постов этого окна.

T9Спринт 2

VKTelegram

Зачем

T12Спринт 2

VKTelegramYouTube

Зачем

Главный дифференциатор: VK-статистика не говорит, «хорошо это или плохо». Своя база снимков позволяет сравнить с похожими по размеру и нише.

  • перцентиль округляется до 5%.

T13Спринт 2

План, цель и алерты отклонений

VKTelegramYouTube

Зачем

Отчёт — снимок, к которому нет повода вернуться. Цель и алерты превращают его в регулярный ритуал и дают материал для VK-дайджеста.

Данные

Цель — новое поле у источника; норма — медиана за 30 дней по снимкам; алерты считаются на бэкенде и отдаются в выгрузке для агента.

Состояния

  • цель не задана → мягкое предложение;
  • нет нормы → алерты не показываем;
  • доставка: отчёт и weekly-дайджест.
Как пользоваться: откройте design/analytics-v2/screens.html — там три экрана целиком (VK, Telegram, YouTube), где новые блоки стоят на своих местах. Задачи T1–T13 здесь разобраны по отдельности, чтобы обсуждать каждую метрику без прокрутки длинной страницы.
